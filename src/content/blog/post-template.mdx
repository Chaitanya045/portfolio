Copy this file to `src/content/blog/<your-slug>.mdx`, then update the frontmatter:

- `title` and `description` are used on the blog index and in link previews.
- `publishedAt` sets the order on the blog index.
- `draft: true` keeps the post out of production. Set it to `false` to publish; the Blog links then appear in the header, footer and ⌘K menu automatically.

## Writing

Posts are MDX, so regular Markdown works, and Astro components can be imported when a post needs one.
