## Overview

I built Zace to learn how coding agents work under the hood: planning, tool calling, context management and safety checks. It's a proof of concept for learning, not a tool meant for everyday use.

It's a command-line agent built with Bun and TypeScript. It works with any model and splits each task in two: a planner writes the steps, then an executor carries them out.

## The runtime

<Flow steps={['Developer intent', 'Planner', 'Executor', 'Validated tools']} />

Session history and tool outputs carry over from one step to the next. When context usage reaches 80%, the history is compacted automatically.

After every file change, LSP diagnostics are fed back to the agent, so it sees type errors as it makes them.

## Safety

- **Zod-validated tool schemas**, so malformed tool calls are rejected before they run.
- **Permission-aware safeguards** around actions that change the workspace.
- **Controlled side-effect boundaries**: every side effect goes through one of three typed tools, keeping autonomous execution auditable.
