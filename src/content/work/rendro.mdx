## Overview

Rendro hosts documentation for teams that keep their docs as plain HTML in the repository. Docs are pushed from a CLI, or from CI, and read in a live workspace with a VS Code-style sidebar tree and inline comments.

## How it works

<Flow steps={['rendro CLI', 'Cloudflare Worker', 'R2 storage', 'Live reader']} />

Publishing runs through Cloudflare Workers and R2. Comments and authentication are backed by Convex.

## Decisions

- **Hash-based diffing**, so only files whose hashes changed are uploaded on each push.
- **Atomic deployments**: a push goes live only once it has been verified.
- **Sandboxed rendering**: published HTML renders in an isolated iframe, exactly as authored.
- **API-key org isolation**, keeping each organisation’s docs separate.
- **Lazy tree loading**, so large doc sets open quickly in the sidebar.
- **Soft deletes and dark mode** in the reader.
